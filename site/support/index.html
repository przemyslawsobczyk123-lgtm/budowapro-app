Wsparcie BudowaPRO

Opisz problem i podaj wersję aplikacji oraz model telefonu. Nie wysyłaj nieocenzurowanych faktur, danych wykonawców ani prywatnych zdjęć budowy.

Napisz e-mail

Kopia danych

Przed zmianą telefonu lub usunięciem aplikacji otwórz w BudowaPRO narzędzie kopii zapasowej, utwórz ZIP i zachowaj go w zaufanym miejscu. Kopia nie jest szyfrowana. Po odtworzeniu sprawdź projekty, dokumenty i zdjęcia przed usunięciem starej kopii.

Skan paragonu lub faktury

Użyj jasnego, ostrego zdjęcia obejmującego cały dokument. Faktury PDF można importować z pliku. Każdy wynik OCR jest szkicem: sprawdź dane i potwierdź pozycje przed zapisem. Gdy skaner systemowy jest niedostępny, użyj importu obrazu lub PDF.

Usunięcie danych

W aplikacji otwórz „Prywatność i prawo” → „Ustawienia prywatności” → „Usuń wszystkie dane BudowaPRO”. Operacja usuwa lokalną bazę i pliki aplikacji. Ręczne kopie oraz eksporty zapisane poza aplikacją trzeba usunąć osobno.

Zgłoszenie błędu

Dołącz kroki prowadzące do problemu, oczekiwane zachowanie, wersję systemu i aplikacji. Jeśli zrzut ekranu zawiera adres, numer telefonu, dane faktury lub lokalizację, zamazuj je przed wysłaniem.
