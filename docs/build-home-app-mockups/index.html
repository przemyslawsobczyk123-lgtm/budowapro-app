Centrum decyzyjne inwestora

Pierwszy ekran pokazuje budzet, ryzyka etapu i najblizsze wizyty. Uzytkownik widzi co ma zrobic dzisiaj, bez szukania w Excelu.

1. Koszt jako obiekt Etap, kategoria, dostawca, VAT, status, zalacznik, gwarancja.
2. OCR bez ryzyka Paragon tworzy propozycje. Budzet zmienia sie dopiero po potwierdzeniu.
3. Checklisty etapow Stan 0 pilnuje przepustow, bednarki i dowodow zdjeciowych.
4. Lokalnie Brak konta, backendu i wysylki dokumentow w MVP.
5. Jedno szybkie wejscie Paragon, zdjecie, glos, decyzja i usterka najpierw trafiaja do szkicow.
6. Pelny cykl domu Budowa konczy sie karta domu z gwarancjami, serwisem i mapa instalacji.
